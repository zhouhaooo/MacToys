# MacToys

MacToys 是一款原生 macOS 菜单栏工具，把键鼠习惯调整、剪贴板历史、窗口分屏、Dock 窗口预览和保持唤醒放在一起，让日常操作更顺手。

支持 **macOS 27 及以上版本**，提供简体中文和英文界面，可跟随系统语言，支持登录时自动启动。

## 功能

### 键鼠映射：按自己的习惯操作

- **Command / Ctrl 互换**：左右两侧同时生效。开启后可用 `Ctrl+C`、`Ctrl+V` 复制粘贴，原来的 Command 键则承担 Ctrl 的功能。
- **Finder 剪切移动**：先用 `Command+X` 标记文件，再到目标文件夹按 `Command+V` 移动；开启键位互换后改用 `Ctrl+X`、`Ctrl+V`。只在 Finder 文件列表中生效，搜索框和重命名输入保留原生行为，可单独开关。
- **鼠标滚轮反转**：统一反转普通鼠标的滚轮方向；触控板和妙控鼠标的连续滚动保持系统设置。
- **快速定位鼠标**：双击 Ctrl，屏幕压暗，聚光灯收拢到指针位置并随指针移动。默认持续 3 秒，可设为 1–30 秒，点击或按键可提前退出；开启键位互换后改为双击 Command。
- **应用例外**：为指定应用保留原生键盘行为，滚轮反转继续生效。可拖入应用或通过选择器添加。

### 剪贴板历史：找回刚才复制的内容

- 自动保存复制的文字和图片，图片记录可单独关闭。
- 支持文字搜索、中文拼音全拼和首字母搜索。
- 面板优先出现在文字光标附近，无法定位时出现在鼠标附近。
- 点击条目，或用方向键选择后按回车，直接粘贴到原来的应用；按 `Esc` 关闭面板。
- 默认保存 **200 条**，可选择 50、100、200、500 或 1000 条；历史内容最多占用 **64 MB**，超出时移除最旧条目。
- 支持一键清空全部历史，也可从设置中打开本地存储位置。

默认按 `Ctrl+V` 呼出历史；开启 Command / Ctrl 互换后改为 `Command+V`。也可以从菜单栏右键菜单打开。

### 窗口分屏：拖到边缘即可整理

| 拖动位置 | 窗口布局 |
| --- | --- |
| 屏幕左侧 / 右侧 | 左半屏 / 右半屏 |
| 屏幕顶部 | 最大化 |
| 屏幕四角 | 对应的四分之一屏 |

分好一半后，**贴靠助手**会让你选择另一个窗口填入剩余区域。把已贴靠的窗口拖离原位时，会恢复分屏前的尺寸。

边缘拖动和贴靠助手均可单独开关。如果系统自带的拖动分屏已开启，设置页会提示冲突，并提供系统设置入口。

### Dock 预览：先看窗口，再切换

- **悬停预览**：鼠标停在 Dock 应用图标上，查看该应用的窗口缩略图；点击卡片即可切换到对应窗口，也可恢复最小化窗口。
- **原位置预览**：悬停缩略图时，在窗口原来的位置和尺寸显示清晰预览，并以浅蓝色边框强调；不抢占焦点，移开或点击即收起。此功能适用于当前桌面上未最小化的窗口。
- **快捷窗口操作**：可在缩略图上关闭、最小化窗口，也可启用中键点击关闭。
- **单窗口切换**：对只有一个窗口的应用，点击 Dock 图标可切换最小化状态。
- **外观调整**：预览图高度支持 50–200 点，可选择“凝实消散”或“飞入飞出”动画，并调整原位置预览的边框宽度和圆角。
- **按应用排除**：为不需要预览的应用设置例外，也可选择是否为没有窗口的应用显示占位面板。

Dock 预览与窗口分屏独立开关。未授予屏幕录制权限时，使用占位卡片代替真实窗口画面。

### 保持唤醒：临时让屏幕和电脑保持清醒

阅读资料、演示或等待任务完成时，可阻止因空闲而发生的屏幕和电脑睡眠。

- 支持 **15 分钟、30 分钟、1 小时、2 小时、4 小时和无限时**。
- **单击菜单栏图标**即可开关，开启时图标显示叶片标记。
- 右键菜单可选择时长、查看剩余时间；开启期间更改时长会重新计时。
- 到期、手动关闭或退出 MacToys 后恢复正常睡眠；合盖和主动睡眠仍由系统处理。

此功能不需要额外权限。

## 开始使用

1. 打开 MacToys，右键点击菜单栏图标，选择“打开设置…”。
2. 按需启用功能，并根据设置页提示授予对应权限。
3. 在“通用”中选择语言、设置登录启动；也可通过设置搜索快速查找选项。

默认开启 Finder 剪切移动、鼠标滚轮反转、定位鼠标、剪贴板历史、分屏和 Dock 预览。Command / Ctrl 互换、保持唤醒和登录启动默认关闭；需要权限的功能在授权后生效。

### 常用操作

下表中的键位指实际按下的物理按键。

| 操作 | 未开启键位互换 | 已开启键位互换 |
| --- | --- | --- |
| Finder 标记剪切 / 粘贴移动 | `Command+X` / `Command+V` | `Ctrl+X` / `Ctrl+V` |
| 呼出剪贴板历史 | `Ctrl+V` | `Command+V` |
| 定位鼠标 | 双击 Ctrl | 双击 Command |
| 切换保持唤醒 | 单击菜单栏图标 | 单击菜单栏图标 |
| 打开菜单 | 右键点击菜单栏图标 | 右键点击菜单栏图标 |

键盘例外应用中，剪贴板历史始终使用 `Ctrl+V`，定位鼠标始终使用双击 Ctrl。若将 Finder 加入例外，其剪切移动改写也会停用。

## 权限与隐私

MacToys 按功能申请权限，无需全部授权即可启动。

| 权限 | 用途 |
| --- | --- |
| 辅助功能 | 键鼠映射、直接粘贴、分屏和 Dock 窗口操作 |
| 输入监控 | 系统事件监听，系统要求时按提示授权 |
| 屏幕录制 | Dock 和贴靠助手中的真实窗口缩略图、原位置预览 |
| 剪贴板读取 | 设为“始终允许”后，在后台记录复制的文字和图片 |

剪贴板内容只保存在本机，路径为 `~/Library/Application Support/MacToys/Clipboard`。不记录 Finder 复制的文件，也会跳过密码管理器等应用标记为隐藏的内容。

应用不要求完全磁盘访问，不包含联网更新或遥测。
